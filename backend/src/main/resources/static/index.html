Enterprise Analytics Platform

Operations intelligence with an AI data analyst

Dashboards, a data-quality-checked ETL pipeline, machine-learning customer segments, daily anomaly reports, and an assistant that answers questions about the business in plain English. It writes the SQL itself, safely, and also reads company policy documents. Built on a synthetic company in 17 Indian cities: about 60,000 orders and 9,500 support tickets.

Ask about the business in plain English

Data questions become one safe, read-only SQL query that you can inspect. Policy questions are answered from company documents, with citations.

How it stays safe

  1. Curated views: the model only sees 7 documented ai.* views, with no personal data.
  2. SQL validator: the query is parsed (sqlglot). It must be a single SELECT on allowed views, with no dangerous functions, and gets a LIMIT.
  3. Least-privilege role: it runs as ai_reader, which can only read the ai schema.
  4. Read-only transaction: with a statement timeout and a row cap, always rolled back.
  5. Budgets: per-user hourly and global daily limits.
