Enterprise Analytics Platform

Operations intelligence for a multi-region business

Revenue, customers, products and support SLAs for a synthetic company operating in 17 Indian cities. That's 24 months of data, about 60,000 orders and 9,000 support tickets. Every chart comes from an analytical SQL query (CTEs, window functions, percentiles) served by a Spring Boot REST API.

  • Java 21
  • Spring Boot 3
  • Spring Security + JWT
  • PostgreSQL
  • Flyway
  • JdbcTemplate + JPA
  • Docker
  • GitHub Actions

Sign in with a demo role. Each role sees different things. Analyst can open the SQL behind every chart, and Admin also gets user management.
